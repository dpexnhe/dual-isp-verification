## 双ISP到底在查什么：两个字段，四种组合

ipinfo返回的JSON里，`asn`描述的是这个IP由哪个自治系统承载，`company`描述的是这个IP段注册在谁名下。双ISP的意思是这两个字段的类型都是`isp`，也就是承载方和注册方都是本地宽带运营商，在风控数据库眼里这个IP长得像个住人的房子拉出来的线，而不是机房机柜里的一台服务器。

| asn.type | company.type | 实际属性 |
| --- | --- | --- |
| isp | isp | 完整双ISP，风控友好 |
| isp | hosting | 半住宅，中间地带，效果不稳定 |
| hosting | isp | 半住宅，同上，看具体场景 |
| hosting | hosting | 普通机房IP，高风控 |

市面上大量标着“住宅IP”“双ISP”的机器落在第二、三行：ASN层面挂着运营商的名字，注册方还是机房，或者反过来。这种IP跑ChatGPT有时碰巧能过，跑TikTok基本靠运气。

## 四步检测：从拿到IP到看清风险分

**第一步，拿到公网IP。** SSH上机，执行`curl ip.sb`或`curl ifconfig.me`，屏幕打印出来的那串IPv4记下来。

**第二步，查两个type。** 浏览器打开`https://ipinfo.io/你的IP`，翻到`asn`和`company`两段找`type`。或者在机器上直接跑：

bash
curl -s https://ipinfo.io | jq '.asn.type, .company.type'


没装jq就用`python3 -m json.tool`格式化输出。两行都打印`isp`，双ISP确认。

**第三步，ping0.cc做辅助。** 执行`curl -L ping0.cc`，看“IP类型”那行返回的是“家庭宽带/Residential”还是“数据中心/Hosting”。这个工具对小众IP段的判断有时不准，只能当参考，结论以ipinfo为准。

**第四步，看风险分。** Scamalytics不用注册，直接访问`scamalytics.com/ip/你的IP`就能看评分。0到25分属于低风险，25分以上要留意，超过75分基本等同于进了黑名单，这种IP换段比调配置有用。想一次跑完CPU、磁盘IO和多家IP数据库的体检，可以用融合怪脚本：

bash
bash <(wget -qO- https://raw.githubusercontent.com/spiritLHLS/ecs/main/ecs.sh)


跑完要几分钟，结果里会列出ipinfo、Scamalytics、AbuseIPDB几家的判断，适合买完机器做一次性记录。

## 检测全绿，TikTok还是起不来：三条排查路径

**IP段被平台整段拉黑。** 某个C段之前被大量用于批量注册，平台把整段加进黑名单，你手上这个IP再干净也没用。这种情况只能换段，换之前问清楚商家新段的历史，或者挑相对小众的段。

**本地环境泄漏。** WebRTC暴露真实IP、DNS查询走了本地运营商、系统时区和IP归属地对不上、浏览器指纹异常，这四条里中任何一条，平台都能判断你在用代理。IP是必要条件，不是充分条件，环境没配好，再贵的住宅IP也白搭。

**Cloudflare按ASN判机器人流量。** CF的风控不只看单个IP，还看这个IP所属ASN整体的机器人流量比例。同一个ASN下如果挤了大量爬虫和批量注册，你这条住宅IP照样会被弹验证码。这个没有配置层面的解法，换段是唯一手段。

还有一条常被混淆的：流媒体解锁和IP质量不是一回事。住宅IP也可能在Netflix、Disney+上解锁失败，原因通常是那个IP段被平台单独拉黑了，跟双ISP属性关系不直接。拿解锁结果反推IP好坏，方向就错了。

## “双ISP”有两种说法，买VPS该认哪一种

第一种是数据库登记口径：同一个IP同时登记在两家ISP名下，一家承载网络、一家注册持有，判定依据就是ipinfo那两个type字段。这个说法有可复现的验证方法，也是本文采用的标准。

第二种是线路冗余口径：同一台机器同时接入两家运营商的物理线路，一条主用一条备用，故障时自动切换。这个说法在卖静态住宅代理的服务商那里更常见，讲的是后端调度架构，跟你在ipinfo上看到的字段对不上。

两种说法都有人用，但你买的是VPS，能验证的只有数据库登记这一层。商家说“双线路冗余”不等于你拿到手的IP有两个isp标记，下单前要一个测试IP自己查，比看宣传语有用。

## 原生IP、双ISP、9929：三个互不替代的属性

原生IP说的是注册地和机器物理位置一致，这个IP可能仍然属于机房。双ISP说的是IP有两个ISP归属。两者独立，一台机器可以“原生但机房”，也可以“双ISP但非原生”。

辨伪有个快办法：看`company.name`里的运营商名字。Comcast、AT&T、Verizon、Charter、Cox这一类是居民宽带运营商，Cogent、Hurricane Electric、Akamai这一类是机房和CDN。名字对不上，宣传语就不用看了。

9929（AS9929）是联通的CUII精品回程，属于线路属性，跟IP属性完全正交。同一台机器可以是“双ISP+9929”，也可以是“双ISP+4837”，还可以是“机房原生IP+9929”。SixNet这条住宅线本身回程已经用了AS10099接AS9929，等于线路和IP两头都占了，不需要再在“要不要9929”上单独纠结。带宽上限方面，9929线路的套餐普遍压得比较低，4837能跑到300Mbps到1000Mbps但晚高峰延迟波动更大，这是两条线路的固有取舍。

## FAQ

**Q：一定要先买才能查双ISP吗？**
是。检测对象是具体IP，没有IP就无从查起。下单前可以向商家索要测试IP，SixNet的测评里出现过测试段，但库存段会变，拿到手的IP仍要自己复检一遍。

**Q：双ISP属性会变吗？**
IP段在数据库里的登记属性一般不会变。商家换段之后，新段要重新检测。你自己换机房、换套餐，也等于换IP，流程重跑一遍。

**Q：ipinfo要付费吗？**
基础查询免费，直接访问`ipinfo.io/你的IP`就能看，个人日常用量在免费额度内。

**Q：检测通过但ChatGPT提示不可用地区，怎么办？**
先排查本地环境：浏览器时区、语言、WebRTC、DNS。这四项都对上了再看IP段历史，同一个段被OpenAI整段标记的情况并不少见，换段比反复重装浏览器有用。

**Q：SixNet能装Windows吗？**
资料里没有官方对住宅线Windows镜像的明确说明，1G、2G内存的档位跑Windows本身也吃力。有桌面端工具需求，开工单问清楚再下单。
